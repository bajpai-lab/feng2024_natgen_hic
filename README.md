# Feng et al. 2024 `nature_gentics_codes`
Codes for analyzing ATAC-Seq, RNA-Seq, CUT&RUN, MPRA, Hi-C and HiChIP data

Forked for use by the Bajpai lab for chromatin conformation analyses in MNT-1 cells

From Yuanqing Feng paper - (Tishkoff lab):
- Source code paper: https://www.nature.com/articles/s41588-023-01626-1
- Source code: https://github.com/fengyq/nature_gentics_codes
- Matching GEO Hi-C(hIP) datasets: https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE248849

# Replication
Environment created using Anaconda with bioconda packages. Package names and versions in `environment.yml`
